**Why text is left blank:** Image models misspell and warp lettering. Generate every visual text-free, then typeset the verbatim microcopy from Section 1.

```

crisp folded edges, soft studio lighting, subtle ambient occlusion, handcrafted 
diorama look, vibrant saturated palette (cobalt blue, tangerine, mint, sunshine

```

PosiBot: friendly retro robot mascot made of folded cardstock, rounded-square head

torso with a small blank chest panel, segmented accordion-paper arms and legs,

```

```
